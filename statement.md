
# New Student Campus Helper

## 1. Problem Statement

New students may face difficulty in finding
important places and services on a new campus.

The New Student Campus Helper provides a
simple digital solution that helps students
find campus places, search for services, and
get useful information through a menu-based
Python program.

## 2. Scope of the Project

The project focuses on providing basic
campus information to new students.

It includes campus place information, place
searching, service searching, quick help,
campus summary, and input validation.

The project can be expanded in the future by
adding more campus places, services, and
additional student-support features.

## 3. Target Users

The main target users of this project are:

- New students
- First-year students
- Students who are unfamiliar with the campus

## 4. High-Level Features

- View campus places
- Search for a campus place
- Find available services
- Get quick help
- View campus summary
- Validate menu choices
- Handle invalid inputs

## 5. Project Objective

The main objective of this project is to
create a simple Python-based campus helper
that makes it easier for new students to
find useful campus information.

The project also demonstrates the practical
use of Python programming concepts such as
functions, lists, dictionaries, loops,
conditional statements, searching, and
validation.
