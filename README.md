
# New Student Campus Helper

## 1. Project Overview

New Student Campus Helper is a Python-based
project designed to help new student find
important campus places and services easily.

The project provides a simple menu-based
system where students can view campus
places,search for a place,find available
service,get quick help,and view a campus
summary.

The project uses basic Python programming
concepts such as functions,lists,
dictionaaries,loops,conditional statements,
searching,and input validation.

## 2. Problem Statement

New students may face difficulty in finding
important places and services on a new
campus.

This project provides a simple digital
helper that allows students to search
for campus places and understand the
services available at those places.

## 3. Features

- View campus places
- Search for a campus place
- Find services available at a campus place
- Get quick help for common needs
- View campus summary
- Handle invalid menu choices
- Display useful information in a simple format

## 6. Project Modules

### main.py
Controls the main menu and overall program flow.

### campus_data.py
Stores information about campus places such
as name,category,location,purpose,and services.

### campus_info.py
Display information anout the available
campus places.

### search.py
Allows the user to search for a campus
place.

###service_finder.py
Helps the user find places that provide a
particular service.

### quick_help.py
Provides quick help for common student
needs.

### summary.py
Displays a summary of the campus
information.

### validation.py
Checls whether the user's menu choice is
valid.

## 7. How to Run the Project

1. Open the project in Google Colab or a
Python environment.
2. Keep all Python files in the same folder.
3. Run the Python files creation cells.
4. Run 'main.py'.
5. Select an option from the main menu.
6. Enter the required information when
asked.
7. Follow the instructions displayed by the
program.

## 8. Main Menu

The project provides the following menu
options:
1. View Campus Places
2. Search Places
3. Find Service
4. Campus Summary
5. Quick Help
6. Exit
